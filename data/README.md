# Data

Los archivos crudos no se versionan.

## Mendeley

Ubica los tres archivos en `data/raw/mendeley/` con sus nombres originales y ejecuta `python scripts/prepare_mendeley.py`.

## Itemlet

Ubica `itemlet_dataset.parquet` o `itemlet_dataset.csv` en `data/raw/itemlet/`.

## GitHub Collaboration

Descomprime `dataset.zip` en `data/raw/collaboration/`.

## SQuaD

No descargues el conjunto completo salvo que dispongas del almacenamiento requerido. Usa subconjuntos orientados a `ISSUES`, `COMMITS`, `RELEASES` y `PROCESS_METRICS`.
