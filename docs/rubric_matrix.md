Base: main remoto `b2d0ca32f0599fc6c2227f2a5eb3e6dea6ff812a`; cierre previo validado integrado sin duplicar soluciones. La auditoría usa el texto de rúbrica **aportado en la solicitud**, no un PDF institucional adicional. No asigna una calificación oficial. «Compatible N4» identifica evidencia documental/técnica alineada con el descriptor; la valoración final corresponde al evaluador. Nivel 3 se menciona como compatibilidad orientativa, sin inventar un descriptor oficial no proporcionado.

Nivel objetivo: **4 para los 27 ítems**. No se declara logrado cuando falta medición, operación real o desempeño humano. Las rutas sin prefijo de docs son relativas a raíz; quality.yml se refiere a .github/workflows/quality.yml.

R7.2 Cr6 no tiene retraining continuo real. RA2 entero tiene preparación, no calificación de ejecución oral; F4/F6 requieren práctica humana de forma explícita.

Los JSON predictivos y Qwen congelados permanecen fuente de verdad. Un CI anterior no valida un HEAD nuevo; consultar la ejecución final exacta en el reporte de entrega.
