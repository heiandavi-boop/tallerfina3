# Validación humana

Esta carpeta contiene una plantilla sin observaciones ni resultados. No se ha ejecutado un estudio de usuarios. El protocolo está en [docs/human_efficiency_validation.md](../../docs/human_efficiency_validation.md).

No completar filas ficticias. Antes de recolectar datos, obtener consentimiento, acordar acceso/retención y predefinir el análisis. La plantilla pide IDs pseudónimos, condición manual/PRUNIN, tiempos y calidad; no recolectar nombres, empleadores ni información de proyectos reales identificables.

La medición de API en `reports/efficiency/` es eficiencia operacional automatizada y no productividad humana.
